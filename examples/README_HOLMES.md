# 福尔摩斯侦探故事 - 交互式剧情模式

## 概述

这是一个完整的交互式侦探故事体验，你可以与三个角色进行对话，体验福尔摩斯破案的全过程。

## 故事背景

**失踪的蓝宝石项链**

艾米丽·威尔逊家族传承的蓝宝石项链在昨晚的宴会后神秘失踪。她来到贝克街221B，请求大侦探福尔摩斯帮助找回这件价值连城的家族宝物。

福尔摩斯和华生医生接受了委托，开始了一天的调查...

## 可用角色

### 🔍 Sherlock Holmes (夏洛克·福尔摩斯)
- **角色**: 私家侦探
- **性格**: 聪明、观察力敏锐、逻辑推理能力强
- **专长**: 犯罪调查、逻辑推理、化学实验

### 📝 Dr. Watson (华生医生)
- **角色**: 福尔摩斯的助手
- **性格**: 忠诚、可靠、善于记录
- **专长**: 医学、协助调查、案件记录

### 👩 Emily Wilson (艾米丽·威尔逊)
- **角色**: 委托人
- **性格**: 焦急、担忧、期待
- **背景**: 项链失窃的受害者

## 使用方法

### 启动故事

```bash
uv run python examples/holmes_interactive.py
```

### 基本对话

**与当前角色对话**（默认是福尔摩斯）：
```
💬 你 -> Sherlock Holmes 🔍: 你好，福尔摩斯先生
```

**切换对话对象**：
```
💬 你 -> Sherlock Holmes 🔍: @watson 华生，你对这个案子怎么看？
💬 你 -> Dr. Watson 📝: @emily 请描述一下项链最后出现的情况
```

### 可用命令

| 命令 | 功能 | 示例 |
|------|------|------|
| `@<角色ID> <消息>` | 与指定角色对话 | `@watson 你好` |
| `/status` | 查看所有角色状态 | `/status` |
| `/schedule <角色>` | 查看角色日程 | `/schedule holmes` |
| `/help` | 显示帮助 | `/help` |
| `/quit` | 退出故事 | `/quit` |

### 角色ID列表

- `holmes` - Sherlock Holmes
- `watson` - Dr. Watson
- `emily` - Emily Wilson

## 角色特性

## 技术说明

### 上下文感知

每个角色在回复时都知道：
- ✅ 当前时间和正在做的事
- ✅ 今天的完整日程
- ✅ 自己的情绪状态
- ✅ 当前的目标
- ✅ 最近的记忆
- ✅ 角色背景和性格

### 记忆系统

所有对话都会被记录：
```python
- 对话会保存到角色记忆中

- 可以引用之前的对话
```

### 作息时间

角色有正常作息：
- **活动时间**: 07:00 - 22:00
- **休息时间**: 22:00 - 07:00

## 自定义故事

### 修改剧情

编辑 `holmes_interactive.py` 中的 `_generate_story` 方法：

```python
plot_points = [
    "08:00 你的剧情点1",
    "10:00 你的剧情点2",
    # ... 添加更多
]
```

### 添加角色

在 `_create_characters` 方法中添加新角色：

```python
new_character = await self.manager.create_agent(
    agent_id="new_id",
    name="Character Name",
    config={
        "role": "角色职业",
        "personality": "性格特点"
    },
    use_llm=use_llm
)
```

### 修改对话风格

调整 `config.get("personality")` 来改变角色性格：

```python
"personality": "冷静、理性、不苟言笑"  # 福尔摩斯风格
"personality": "热情、健谈、幽默风趣"  # 华生风格
```

## 故障排除

### 问题：角色不回复

**可能原因**:
- 角色在休息时间（22:00-07:00）
- LLM调用失败

**解决方案**:
- 使用 `/status` 检查角色状态
- 查看是否在休息时间

### 问题：对话没有上下文

**解决方案**:
- 这个问题已在最新版本修复
- 角色现在会知道自己的日程、情绪、目标等

### 问题：无法切换角色

**解决方案**:
- 使用正确格式: `@watson 消息内容`
- 确保角色ID正确: holmes, watson, emily
